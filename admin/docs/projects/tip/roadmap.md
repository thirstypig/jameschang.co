# TIP — roadmap

> Renamed from **Spar** in July 2026. Doc IDs moved `*-SPAR-*` → `*-TIP-*` with the
> product; the old IDs are retired, not reused.

- **Done:** the live voice session, the scored debrief, and a persona builder for
  creating your own counterpart.
- **Now:** personal logins — the keystone of the launch cluster.
- **Then:** saved sessions you can replay, then a score trend across sessions, then
  cross-session pattern insights.
- **Later:** paid plans with usage limits; a video-call avatar; an observer/grading
  mode; multi-seat for teams.
