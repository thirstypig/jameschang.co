The jameschang.co app.

A personal tool that lets the site owner manage their own Gmail through an AI assistant. Not a public service.

/01

what it is

The jameschang.co app is a personal productivity tool. It connects the site owner's own Google account to an AI assistant (Anthropic's Claude, running in Claude Code on the owner's computer) so the owner can manage that email by asking in plain language.

/02

what it does

When the owner asks, the app uses the Gmail API to:

  • search and read the owner's own email
  • draft replies for the owner to review and send
  • organize messages with labels, and move unwanted messages to spam or trash

Every action is started by the owner. The app does not run on its own and does not send email without the owner's review.

/03

who can use it

Only the site owner, with the owner's own Google account. The app is not offered to the public, has no sign-up, and does not access anyone else's Google data.

/04

how google data is handled

Email content is used only to answer the owner's request at that moment. It is not stored by this website, not sold, not used for advertising, and not used to train general-purpose AI models. Use of Google user data follows the Google API Services User Data Policy, including the Limited Use requirements. Details are in the privacy policy.

/05

what it never does

The app does not generate, edit, or distribute images or video of any kind. It is never used to create AI-generated Non-Consensual Intimate Imagery (NCII) or any sexual content, and Google APIs are not used for any such purpose.
